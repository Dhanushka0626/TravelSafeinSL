# TravelSafeinSL
🌴 Travel Safe — Explore Sri Lanka with Confidence

TravelSafeinSL is a modern, responsive web landing page designed for a Sri Lanka–based travel service that caters to foreign tourists.
The platform highlights the island’s top destinations, travel packages, and local experiences while promoting safety, comfort, and personalized service.

✨ Features

🏝️ Tour Highlights: Showcase of top Sri Lankan destinations and experiences.

🧭 Travel Assistance: Information for foreign travelers about routes, safety, and support.

📱 Responsive Design: Works seamlessly on desktop, tablet, and mobile.

💬 Contact & Inquiry Section: Easy communication for trip planning or booking.

⚡ Optimized for GitHub Pages: Fast-loading static design suitable for quick deployment.

🚀 Getting Started

1️⃣ Clone or Download

git clone https://github.com/<your-username>/travel-safe-srilanka.git

cd travel-safe-srilanka

2️⃣ Run Locally

Use a simple local server (Python example):

python -m http.server 8080


Then visit http://localhost:8080

3️⃣ Deploy on GitHub Pages

Go to Settings → Pages

Set the Source to main branch → / (root)

Save — your site will be live within minutes!
